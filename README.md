# Multi-Hazard Intelligence Lab (MHIL)

Quarto website for the Multi-Hazard Intelligence Lab at King's College London.

Website: https://mhil-kcl.github.io

Run `quarto preview` to preview and `quarto render` to rebuild the website into `docs/`. GitHub Pages should publish from the `main` branch, `/docs` folder.

Edit `.qmd` files for page content, `styles.css` for styling, `_quarto.yml` for navigation, and `_footer.html` for the shared footer. Update `_opportunities.qmd` for the homepage PhD feature and `join-us.qmd` for full vacancy details. Current TREES deadline: 14 December 2026, 17:00 UK time. Archive expired calls.

Code and dataset links are maintained in `code-data.qmd`. Publications are in `publications.qmd`.
